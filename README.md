# 八大爆款元素

面向 Codex 等支持 Agent Skills 的智能体，将普通短视频选题改造成带有情绪抓手的标题，并生成前三秒钩子、分镜、口播及评论区互动方案。

八个元素：**成本、人群、奇葩、最差、头牌、荷尔蒙、反差、怀旧**。单个选题通常组合 1—3 个元素，以相关性和可拍性为先。

显示名称：**八大爆款元素**；调用标识：`bada-baokuan-yuansu`。

## 安装

将本仓库作为一个完整 Skill 文件夹安装，确保 `SKILL.md` 位于技能目录根部。

在项目根目录执行：

```bash
git clone https://github.com/haibo0505/bada-baokuan-yuansu.git .agents/skills/bada-baokuan-yuansu
```

全局安装可将完整文件夹放入 `$CODEX_HOME/skills/bada-baokuan-yuansu`。默认 Codex 配置目录下的 `skills` 也可使用指向其他磁盘的目录链接。新安装的技能从下一轮聊天开始使用；若客户端未刷新，可重新打开聊天。

运行本 Skill 本身无需 Python、Node、API Key 或第三方包。若任务要求实时热点、新闻或商品事实，需要当前客户端具有可用的搜索、浏览或相关连接工具；本 Skill 不自带数据接口。

## 使用

```text
使用 $bada-baokuan-yuansu，为高跟鞋设计五个抖音广告选题。
每个标注八大元素中的组合；选一个展开成25秒脚本，提供三个开场、逐镜画面、完整口播和购买引导。
不要编造价格、材质、舒适性卖点或明星代言。
```

也可说：“用八大爆款元素，把这个普通选题改成五个不同角度。”

默认工作流：原题诊断 → 3—5 个选题方案与元素组合 → 最优方案的分镜脚本 → 评论区互动和发布文案。用户指定的数量、时长与格式优先。

## 方法与边界

- “60分→90分”属于方法论比喻，不代表实际评分或流量、成交承诺。
- 区分反差与怀旧：身份跨界是反差，唤起过去记忆才是怀旧。
- 荷尔蒙元素强调尊重、自愿的成人情绪互动，不等于擦边画面。
- 明星同款、销量、价格、功效与内幕需要证据；不虚构背书或实测结果。
- 评论建议只用于真实互动，不冒充消费者、不捏造口碑。
- 依据用户提供的 `skill_md.md` 整理，保留八大元素及分镜结构，调整名称并补充上述事实与使用边界。
